# Odoo Mail Sync für Microsoft 365 – Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Two LGPL-3 Odoo 18 modules that mirror Microsoft 365 mailboxes via Graph into Odoo and link every conversation to matching contacts and their open opportunities, following the spec `docs/superpowers/specs/2026-09-30-mail-sync-design.md`.

**Architecture:** `mail_sync_microsoft` owns the Graph transport (`services/graph.py`), the registry models, the sync orchestration (`services/sync.py`) and contact matching (`services/router.py`); it never knows CRM. `crm_mail_sync` extends the router with opportunity rules (`services/lead_rules.py`) and adds UI on `crm.lead`. All background work runs through OCA `queue_job`; all Graph access goes through one client class that the tests replace with `FakeGraph`.

**Tech Stack:** Odoo 18.0 Community, Python 3.12, `requests`, `msal` (OAuth client-credentials and auth-code), OCA `queue_job`, ruff + pylint-odoo, GitHub Actions with the official `odoo:18.0` image and Postgres 16.

### Task 4: GraphClient

**Files:** `services/graph.py`, `tests/fake_graph.py`, `tests/test_graph.py` (unit with `requests` mocked)

- [ ] Interface (used by everything else):
  ```python
  class GraphClient:
      def __init__(self, token_provider, session=None, base_url="https://graph.microsoft.com/v1.0"): ...
      def organization(self) -> dict            # verifiedDomains
      def list_folders(self, upn) -> list[dict]   # recursive childFolders, fields id, displayName, wellKnownName, parentFolderId
      def delta(self, upn, folder_id, delta_link=None, since=None, select=SELECT) -> tuple[list[dict], str|None, str|None]  # rows, next_link, delta_link
      def message(self, upn, message_id) -> dict
      def mime(self, upn, message_id) -> bytes
      def attachments_meta(self, upn, message_id) -> list[dict]
  ```
  Every request sends `Prefer: IdType="ImmutableId"`; 429/503 raise `GraphThrottled(retry_after)`; 410 raises `GraphGone`; 401 raises `GraphUnauthorized`; other 4xx raise `GraphError`.
- [ ] `TokenProvider` implementations: `AppTokenProvider(tenant, client_id, secret|cert)` using `msal.ConfidentialClientApplication.acquire_token_for_client(scopes=[".default"])` with in-memory cache; `DelegatedTokenProvider(tenant, client_id, secret, refresh_token, on_refresh)` using `acquire_token_by_refresh_token`.
- [ ] `FakeGraph` implements the same interface from in-memory dicts: mailboxes → folders → messages; supports `raise_throttle_once`, `raise_gone_once`, delta paging by `page_size`, `removed` entries.
- [ ] Tests: delta paging joins pages, headers include ImmutableId preference, 429 maps to `GraphThrottled` with seconds, 410 to `GraphGone`.
- [ ] Commit: `feat(core): Graph client and fake`.

### Task 6: Ingest and sync pipeline

**Files:** `services/ingest.py`, `services/sync.py`, jobs on `mail.sync.mailbox`, `tests/test_ingest.py`, `tests/test_sync.py`

- [ ] `ingest(env, registry_row, mime_bytes, target)`: `env["mail.thread"].with_context(mail_sync_import=True).message_process(target._name, mime_bytes, thread_id=target.id, save_original=False)`; afterwards find `mail.message` by `message_id`, cap attachments (unlink oversize, keep link in body note), set `registry.mail_message_id`. Handle `message_process` returning an existing thread id (reply routing) by re-reading the target.
- [ ] `sync.py`: `discover_folders(mailbox)`, `backfill(mailbox, folder)`, `delta(mailbox, folder)`, `process_message(mailbox, folder, graph_row)`: upsert registry row, run Router, apply visibility, ingest when shared and target exists, write `reason`; commit-safe batches of 200 with job continuation.
- [ ] Jobs on `mail.sync.mailbox`: `job_discover_folders()`, `job_backfill(folder_id, since, page_link=None)`, `job_delta(folder_id)`; throttling → `RetryableJobError(seconds=retry_after)`; `GraphGone` → folder `needs_full_resync` and requeue backfill; `GraphUnauthorized` → mailbox `auth_error` + activity for owner.
- [ ] Cron `mail_sync_delta` every 5 min enqueues `job_delta` for each active included folder whose last job is not pending (identity_key to avoid duplicates); housekeeping cron deletes `unmatched` rows older than `retention_days`.
- [ ] Tests: end-to-end with FakeGraph (2 mailboxes, inbox+sent, 6 messages incl. internal, automatic, reply thread, private prefix) → registry states and chatter messages as expected; delta removal marks `removed`; throttle → RetryableJobError; gone → resync flag; idempotent second run.
